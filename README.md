# Projeto 01 — Análise de Vendas com Excel

## 📊 Objetivo

Desenvolver uma análise de dados de vendas utilizando o Microsoft Excel, com o objetivo de identificar o faturamento total, analisar o desempenho dos vendedores e avaliar o faturamento dos produtos.

## 🛠️ Ferramentas utilizadas

* Microsoft Excel
* Fórmulas
* Tabelas dinâmicas
* Gráficos de colunas
* Dashboard

## 📈 Análises realizadas

Durante o projeto foram realizadas análises de:

* Faturamento total;
* Número de vendas;
* Faturamento médio por venda;
* Faturamento por vendedor;
* Faturamento por produto;
* Relação entre vendedor e produto;
* Principais resultados e oportunidades de análise.

## 📌 Principais resultados

* **Faturamento total:** R$ 55.160,00
* **Número de vendas:** 12
* **Faturamento médio por venda:** R$ 4.596,67
* **Vendedor com maior faturamento:** Maria — R$ 18.100,00
* **Produto com maior faturamento:** Notebook — R$ 24.500,00
* **Segundo produto com maior faturamento:** Monitor — R$ 20.400,00

## 💡 Conclusões

A análise mostrou que Notebook e Monitor apresentaram os maiores faturamentos entre os produtos analisados.

Entre os vendedores, Maria apresentou o maior faturamento individual, totalizando R$ 18.100,00.

A partir dos resultados, recomenda-se acompanhar o desempenho de Notebooks e Monitores e avaliar oportunidades para aumentar as vendas desses produtos.
